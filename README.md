# 🇮🇳 Bharat Utsav – Experience the Magic of India

## 📖 About the Project
**Bharat Utsav** is a simple and attractive website that celebrates India's rich cultural heritage, festivals, traditions, and unity in diversity. It introduces visitors to some of India's most popular festivals through images and short descriptions.

## ✨ Features
- **Navigation Bar:** Easy navigation to Home, Festivals, and Heritage sections.
- **Home Section:** Welcomes visitors with the message "Experience the Magic of India."
- **Festivals Section:** Showcases five Indian festivals:
  - 🪔 Diwali
  - 🎨 Holi
  - 🌺 Durga Puja
  - 🌼 Onam
  - 🙏 Navratri
- **Cultural Heritage Section:** Highlights India's music, dance, art, food, and traditions.
- **Responsive Navigation Links:** Allows users to jump to different sections of the webpage.
- **Festival Images:** Uses online images to make the website visually appealing.

## 🛠️ Technologies Used
- **HTML5:** Creates the structure and content of the webpage.
- **CSS3:** Styles the website and improves its appearance.
- **Online Images:** Adds visual representations of Indian festivals.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `index.css` are in the same folder.
4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
5. Explore the different sections of the website.

## 🎯 Project Objective

The main objective of Bharat Utsav is to celebrate India's cultural diversity and spread awareness about its festivals and traditions through a simple, interactive, and visually appealing webpage.

Bharat Utsav is a small step towards celebrating the beauty of Indian culture and the spirit of unity in diversity.
